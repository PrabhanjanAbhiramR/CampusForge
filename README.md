# CampusForge

Frontend foundation for CampusForge, a university research intelligence platform.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Source structure

```text
src/
  assets/       Static assets imported by application code
  components/   Reusable UI components
  features/     Feature-focused modules
  hooks/        Shared React hooks
  layouts/      Application layouts
  lib/          Shared utilities and integrations
  pages/        Route-level views
  types/        Shared TypeScript types
```
